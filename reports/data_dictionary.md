# Data Dictionary

| Column | Description | Data Type | Analytical Use |
|---|---|---|---|
| Customer ID | Unique customer identifier | Integer | Customer counting only |
| Age | Customer age | Integer | Demographic segmentation |
| Gender | Customer gender | Text | Customer comparison |
| Item Purchased | Product purchased | Text | Product analysis |
| Category | Product category | Text | Category performance |
| Purchase Amount (USD) | Current recorded purchase value | Numeric | Spending analysis |
| Location | Customer's US state | Text | Geographic analysis |
| Size | Product size | Text | Product preference |
| Color | Product colour | Text | Product preference |
| Season | Purchase season | Text | Seasonal analysis |
| Review Rating | Customer review score | Numeric | Satisfaction analysis |
| Subscription Status | Subscription indicator | Text | Subscriber comparison |
| Shipping Type | Delivery method | Text | Shipping analysis |
| Discount Applied | Discount indicator | Text | Discount analysis |
| Promo Code Used | Promotional-code indicator | Text | Redundancy validation |
| Previous Purchases | Number of previous purchases | Integer | Purchase-history indicator |
| Payment Method | Payment method used | Text | Payment preference |
| Frequency of Purchases | Stated purchase frequency | Text | Behaviour segmentation |
