# KPI Dictionary

## 1. Purpose

This KPI dictionary defines the key performance indicators used in the Consumer Shopping Behaviour Analysis project.

It ensures that stakeholders, business analysts and data analysts interpret each metric consistently.

> Important: Each customer appears only once in the dataset. Therefore, `Purchase Amount (USD)` represents the customer's current recorded purchase value—not lifetime revenue.

---

## 2. Executive KPIs

| KPI | Business Definition | Calculation | Data Field | Available? |

## 5. Discount KPIs

| KPI | Business Definition | Calculation |
|---|---|---|
| Discount Usage Rate | Percentage of recorded purchases with a discount | Discounted records ÷ total records × 100 |
| Discounted Purchase Value | Total value associated with discounted purchases | Sum of purchase amount where discount = Yes |
| Discounted Value Contribution | Percentage of total value from discounted purchases | Discounted value ÷ total value × 100 |
| Average Discounted Purchase Value | Average value of discounted purchases | Discounted value ÷ discounted records |
| Average Non-Discounted Purchase Value | Average value of non-discounted purchases | Non-discounted value ÷ non-discounted records |
| Purchase-Value Difference | Difference between discounted and non-discounted averages | Discounted average − non-discounted average |
| Category Discount Usage Rate | Percentage of purchases discounted within each category | Discounted category records ÷ category records × 100 |

| KPI | Current Value |

### Interpretation rule

The purchase-value difference is descriptive. It does not prove that discounts caused purchase values to increase or decrease.

## 14. Data Governance and Interpretation Rules

- `Customer ID` is used only for customer identification and distinct counting.
- `Customer ID` must not be used as a predictive-model feature because it is ordered by gender.
- Missing ratings must be excluded only from rating-based calculations.
- `Promo Code Used` should be excluded from modelling because it duplicates `Discount Applied`.
- Recorded purchase value must not be described as lifetime revenue.
- Previous-purchase count must not be treated as complete transaction history.
- Statistical association must not be presented as causation.
- KPI thresholds and business rules must be documented and reviewed with stakeholders.
- The same KPI definition must be used consistently across Python, SQL and Power BI.
